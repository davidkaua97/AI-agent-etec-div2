# Stack técnica

## Decisão inicial

O projeto será desenvolvido com TypeScript e React no front-end, com SQLite como banco leve para persistência inicial.

## Tecnologias propostas

- TypeScript: tipagem segura e manutenção mais previsível.
- React: base para interfaces modernas e componentes reutilizáveis.
- SQLite: solução simples para protótipo e dados iniciais.
- CSS moderno: layout responsivo e visual institucional atrativo.
- Navegadores modernos: suporte prioritário para desktop e mobile.

## Estrutura de uso

- Front-end para apresentação institucional, catálogo de cursos e notícias.
- Área administrativa com login para cadastro e gestão de notícias.
- Dados de cursos baseados no site institucional antigo, com possíveis descrições e matérias em mock inicial.

## Observações

- A stack foi escolhida para priorizar confiabilidade, familiaridade e velocidade de desenvolvimento.
- O uso de SQLite atende a necessidade imediata do projeto sem aumentar a complexidade inicial.
